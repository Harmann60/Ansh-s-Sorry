## 🌸 Why This Repository Exists

This isn't a typical software project. There are no roadmaps, sprint boards, or complex architectures here—just an honest attempt by **Ansh** to apologize to **Parul**.

Sometimes when you mess up, a regular text message doesn't show how much you truly care or how much you've been reflecting. This website was built from scratch as a quiet, heartfelt digital letter and a gallery of 7 favourite memories worth holding onto.

## ✨ What's Inside the Website

- **The Opening Note:** A calm, gentle entrance made specifically for Parul.
- **The Letter:** An honest, no-pressure apology taking full responsibility.
- **7 Memories Worth Remembering:** A curated scrapbook and polaroid gallery of 7 real moments together.
- **Soft Piano Ambience:** Optional background music to accompany the letter.
